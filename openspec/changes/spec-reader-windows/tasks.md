# Tasks — Reader Windows for Workspace Documents

## 1. Document Watch (openspec-core)

- [x] 1.1 Create `crates/openspec-core/src/document_watch.rs` with the registry's value types — a `DocumentKey` pairing a canonical browse root with a forward-slash relative path, and a `DocumentChange` carrying the same pair — deriving the traits the broadcast channel and the `HashMap` need, and declare the module in `lib.rs` (`document-watch`: *Per-Document Watch Registration*)
- [x] 1.2 Implement `DocumentWatcher` holding a `notify` + `notify-debouncer-full` watcher, a `HashMap<PathBuf, DirEntry>` of watched parent directories, and a tokio broadcast sender, cheaply cloneable behind an `Arc` with the processing task holding a `Weak` so the watcher drops cleanly — mirroring `watcher.rs`'s ownership shape (`document-watch`: *Watch Cost Is Bounded by Open Documents*)
- [x] 1.3 Implement `acquire(key)` establishing a `RecursiveMode::NonRecursive` watch on the document's **parent directory** on the first registration, and joining the existing entry on subsequent ones. Watch the directory, never the file path — an atomic-rename save unlinks the inode a file-level watch binds to, and the watch then goes silent while still appearing healthy (`document-watch`: *The Watched Path Is the Parent Directory*, `design.md`: *Decision 5*)
- [x] 1.4 Implement `release(key)` decrementing the reference count, unwatching the parent directory only when the last registration for that directory is released, and returning successfully when no registration is held (`document-watch`: *Watch Registration Is Reference-Counted*)
- [x] 1.5 Filter each debounced batch to events whose path's file name matches a registered document in that directory, and emit one `DocumentChange` per affected document per batch (`document-watch`: *Document Change Notification*)
- [x] 1.6 Re-establish a watch whose directory was removed and later recreated, so a document restored at the same address resumes notifying (`document-watch`: *The Watched Path Is the Parent Directory* — replaced-directory scenario)
- [x] 1.7 Write `crates/openspec-core/tests/document_watch.rs` covering: an in-place modification notifies; an **atomic-rename save notifies, and a second and third consecutive rename save also notify** (the regression a file-level watch would pass once and then fail); a sibling file's modification does not notify; two registrations for one document establish one watch and survive one release; the last release unwatches; releasing an unheld key is a no-op; a burst within the debounce window yields one notification; and a removed-then-recreated directory re-arms. Make timing deterministic by waiting on the notification channel rather than on a sleep, following `watcher.rs`'s `recompute_gate` pattern (`design.md`: *Risks / Trade-offs* — this module is inside the mutation gate)
- [ ] 1.8 Run `cargo mutants --in-diff` over this module's diff and close every survivor with an assertion, or record an exclusion with its reason in `.cargo/mutants.toml`
