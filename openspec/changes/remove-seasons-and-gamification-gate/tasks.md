> **Ordering note.** The schema's default task order is core → shell → frontend, chosen so the workspace stays green throughout. This change is a pure deletion, which inverts that: removing `seasons.rs` first would break every consumer at once. The groups below run the dependency graph in reverse — leaves first, core last — which serves the same goal. See design.md, *Peel outside-in, keeping the tree green*.
>
> **Preconditions.** Run `bun run build` once before the first `cargo test` in a fresh worktree, or the Tauri and web crates cannot build (design.md, Risks). Symbol names below were read from source — the equip/locker commands are `set_equipped_treatment` and `get_treatment_locker` (Rust type `TreatmentLocker`), *not* `equip_treatment` / `treatment_wardrobe`.
