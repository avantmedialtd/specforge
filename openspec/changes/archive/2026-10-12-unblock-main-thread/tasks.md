## 1. Registry: gather/apply split (openspec-core)

- [x] 1.1 In `crates/openspec-core/src/registry.rs`, add `WorktreeFacts` and the free function `gather_worktrees(&RepoId) -> WorktreeFacts`. It returns the sorted, canonical, non-prunable working-tree roots, plus the subset with an `openspec/` directory. It takes no `&self`. Factor its filtering (prunable dropped, `canonicalize`, `is_working_tree`, sort, `openspec/` subset) into a function over `git::worktree_list`'s `Vec<WorktreeInfo>`, so the filter is testable with hand-built `WorktreeInfo`s over temp dirs and no git. (`workspace-registry`: *Registry Lock Excludes Git Subprocesses*)
- [x] 1.2 Add `WorkspaceRegistry::apply_reconcile(&mut self, &RepoId, &WorktreeFacts)`, holding the current registry-dependent body of `reconcile_repo` (`registered_at_a_root`, sorted insertion, vanished-entry removal). Re-express `reconcile_repo` as gather + apply. Do the same for `discover_and_collect`, which `register_resolved` uses.
- [x] 1.3 Add `RegistrationFacts` and `gather_registration(PathBuf) -> Result<RegistrationFacts, RegistrationError>`. It holds the existence and directory checks, `canonicalize`, `git_common_dir`, the `openspec/`-or-`worktree_toplevel` root choice, `too_broad_without_openspec` and the repository's `WorktreeFacts`, with errors raised in today's order. Add `apply_registration(&mut self, RegistrationFacts)` with the `AlreadyRegistered` / promotion / insert decisions and `save()`. Re-express `register_resolved` as gather + apply.
- [x] 1.4 Add a registry `generation: u64`, bumped on every insert, removal and promotion of `entries` (both applies, and `unregister`'s removal and cascade), with a getter. A no-op apply does not bump it. Make both applies return a `Stale` outcome, changing nothing, when the caller's recorded generation no longer matches.
- [x] 1.5 Add the drivers `reconcile_unlocked_with(&Mutex<WorkspaceRegistry>, &RepoId, gather)` and `register_unlocked_with(&Mutex<WorkspaceRegistry>, PathBuf, gather)`. Each reads the generation under a short lock, gathers unlocked and applies under the lock. On `Stale` it retries, up to 3 unlocked attempts in all, then falls back to one gather under the lock. Add the production wrappers that pass `gather_worktrees` and `gather_registration`.
- [x] 1.6 Test `apply_reconcile` with synthetic `WorktreeFacts` and no git. Cover: a new worktree added; a vanished one removed; a non-OpenSpec worktree skipped unless the repo is registered at a root; a prunable `WorktreeInfo` dropped by 1.1's filter (and so removed on apply); and output order matching the pre-split `reconcile_repo` on a fixture repo.
- [x] 1.7 Test `apply_registration`. Cover: `AlreadyRegistered` when the folder became user-registered after the gather; promotion when the folder was added as `Discovered` after the gather; and an unchanged persisted file and order compared with `register_resolved` (`workspace-registry`: *Registration Persistence*).
- [x] 1.8 Test the drivers deterministically with an injected gather closure that mutates the registry (bumping the generation) on its first call. Assert that the closure ran exactly twice and that the result is the serial-equivalent one. Add a closure that races on every unlocked attempt. Assert that it ran exactly 3 times unlocked, then once under the fallback, and that the result is correct. The exact counts kill the off-by-one mutants on the retry bound. Add a closure that asserts `registry.try_lock()` succeeds while it runs, which proves the gather holds no lock. (`workspace-registry`: *Repeated races fall back to a locked gather and still complete*)
- [x] 1.9 Assert that `generation` changes on insert, removal (including `unregister` and its cascade) and promotion, and does not change on a no-op reconcile. This kills the mutants on the bump sites.
