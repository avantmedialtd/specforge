> **Ordering note.** `openspec/config.yaml`'s `rules.tasks` prescribes core → shell → frontend, chosen so the workspace stays green throughout. This change is a pure deletion, which inverts that: removing from `openspec-core` first breaks four downstream crates at once. The groups below run the dependency graph in reverse — consumers first, producer last — which serves the same intent. This matches the seasons removal (`openspec/changes/archive/2026-08-13-remove-seasons-and-gamification-gate/tasks.md`). See design.md, *Peel outside-in — invert the schema's prescribed task order*. Do not "fix" the order back.
>
> **Atomicity.** Groups 6 and 7 contain the one pair that cannot be separated: `compute_garden`'s signature and its single call site in `openspec-app`. Everything else could be split, but the whole change lands as **one commit** so each IPC type moves together with its hand-written `src/types.ts` mirror — see design.md, *Land as one commit*.
>
> **Line numbers** below were read from source at authoring time. Re-grep before editing by number; several deletions shift the lines beneath them.
