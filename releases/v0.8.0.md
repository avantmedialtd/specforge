SpecForge v0.8.0

Two new ways to watch your work: a full terminal frontend, and an opt-in Claude usage gauge.

## ✨ Highlights

- **Terminal UI (`specforge-tui`)** — a new terminal-native frontend built on ratatui/crossterm: a full interactive master-detail OpenSpec browser, the gamified dashboard, and the season ladder, all live-updated from the same watcher the desktop app uses. One binary, three modes — the full interactive TUI, `--status` (print a snapshot and exit; pipeable and CI-friendly), and `--line` (a single ambient status line for a shell prompt or tmux status bar, the terminal twin of the desktop tray badge).
- **Claude quota status line** — an opt-in gauge (default **off**) for your Claude Code usage. It reads the local OAuth token read-only, polls Anthropic's usage endpoint, and shows your 5-hour and weekly utilization — green, orange (≥70%), or red (≥90%) — switching to a reset countdown when a window is spent. It appears in the desktop sidebar footer and the TUI title bar, and refreshes about once a minute. No token is ever written or logged, and nothing leaves your machine until you turn it on.

## 🔧 Improvements

- **The terminal UI is now a downloadable binary.** Each release attaches a standalone `specforge-tui` archive per platform (macOS universal, Linux x64, Windows x64), so you can grab and run it without building from source.

### Downloads

- **macOS** — `SpecForge_0.8.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.8.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.8.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.8.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.8.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.8.0_windows-x64.zip`.
