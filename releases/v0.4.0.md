SpecForge v0.4.0

A clearer sidebar and a more honest dashboard.

## ✨ Highlights

- **Two-line change rows** — single-change rows now stack the change name on top and the branch plus status underneath, so a long name can never hide the worktree/branch label again. Each row is colour-coded to its workspace via a side rail and a tinted branch chip.
- **Live "in flight" dashboard tile** — the second progress tile now counts the changes you have active right now instead of the ones created today, so it reads 0 once you've shipped everything (no more phantom "started 3" on a cleared day).

## 🔧 Improvements

- The Tasks node now collapses by default for every change, so expanding a change shows a tidy four-row artifact list instead of dumping its entire task tree. The progress meter and ✓ still show whether it's open or closed.
- Inline-code chips in the detail pane and settings help now have a firmer, clearly visible outline, so identifiers and paths read as code at a glance.
- Maintainers can run the app from several git worktrees side by side without dev-server port clashes, via the new `bun run wt:dev` slot allocator.

## 🩹 Fixes

- Archiving a change is no longer mistaken for a deletion when it lands in a dated `archive/YYYY-MM-DD-<id>/` folder. Non-git (flat) workspaces now correctly fire the desktop notification and record the "shipped" achievement.
