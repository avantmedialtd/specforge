SpecForge v0.10.0

Working-tree git status at a glance, a sidebar that holds its place, and a much lighter background footprint.

## ✨ Highlights

- **Working-tree status indicators.** SpecForge now shows git awareness of your specs at a glance. Each change carries a commit-state chip — **committed**, **modified**, or **untracked** — so a brand-new spec that exists only uncommitted in a worktree is obvious, and each repository node gains a "dirty" dot when any of its worktrees has uncommitted work, with a distinct mark when that work includes specs. It's derived from a single `git status` per worktree and stays live as you stage and commit, so you can see which repos and worktrees carry unsaved work without leaving the tree.

## 🔧 Improvements

- **The sidebar respects your configured order.** Top-level repositories and workspaces now render in a stable order that matches your configuration, instead of reshuffling on every change, file edit, or refresh. The order is preserved both in memory and on disk, so the tree no longer jumps around as you work — and no registered workspace is dropped in the process.

## 🩹 Fixes

- **Much lower idle CPU when several repositories are registered.** SpecForge could pin a CPU core in the background as you tracked more repositories: a single git change in one repo re-ran `git status` across every worktree of *every* repo, each repo held four filesystem watchers, and a status check could re-trigger itself in a tight loop. Now a git change refreshes only the repository it happened in, each repository uses a single watcher, and the self-triggering loop is eliminated — background CPU no longer scales with how many repos you track.

### Downloads

- **macOS** — `SpecForge_0.10.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.10.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.10.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.10.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.10.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.10.0_windows-x64.zip`.
