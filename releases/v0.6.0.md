SpecForge v0.6.0

The dashboard learns the shape of your day.

## ✨ Highlights

- **Commit garden** — the dashboard grows a garden along its bottom: one faithful little git graph per workspace, drawn from *today's* commits, with nodes tinted by who committed and refreshing live (it re-scopes at midnight). The same lane layout as the commit rail, now multi-repo and today-scoped.
- **Today's ships** — the Recent feed is reborn as a daily wins shelf: the changes you *archived* today, aggregated across every workspace, newest first — with a relative "archived 2h ago" when git is available, and an honest quiet-day note when nothing's shipped yet.
- **Author aliases** — fold a contributor's scattered git identities (work email, personal email, a `noreply` GitHub address) into one named person on the leaderboard, instead of split rows. Settings → Identity gains a free-form add form, so you can record aliases by hand — including extra identities for yourself.

## 🔧 Improvements

- **Full-width Archive & Settings** — both views now span the full detail pane, matching the Dashboard, with the markdown reader staying at its comfortable reading width.

### Downloads

- **macOS** — `SpecForge_0.6.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.6.0_x64-setup.exe` (installer, recommended — ensures
  the Microsoft Edge WebView2 runtime) or `SpecForge_0.6.0_x64-portable.exe`
  (single file; uses the system WebView2 runtime, preinstalled on Windows 11 and
  maintained Windows 10 — use the installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.
