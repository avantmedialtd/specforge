SpecForge v0.0.1

SpecForge is here — a menu-bar companion for your OpenSpec workspaces, now a real desktop app you can install.

## ✨ Highlights

- **A desktop app for OpenSpec** — SpecForge lives in your menu bar and watches every registered OpenSpec workspace, so you can see what's in flight at a glance and drill into any change tree without opening an IDE.
- **Git worktree awareness** — register a repo and SpecForge auto-discovers its other worktrees, including ephemeral ones agents spin up. A change that exists across several worktrees shows as one logical change with per-instance children, giving you a live view of all parallel work on a project.
- **Status-board change tree** — the sidebar expands by default, turning the four-artifact icons (proposal / design / tasks / specs) and per-task checkboxes into an at-a-glance status board instead of a stack of folders to click open.
- **Tray badge with spec-activity glyph** — the active-change count rides in the menu bar, and the tray glyph changes when a change touches capability specs, so high-leverage work is visible without opening the window.
- **Engineered-minimal identity** — a refreshed visual style on a small token system plus new SpecForge brand icons across the dock, installer, and platform asset sets.

## 🔧 Improvements

- Type and spacing scale retuned for comfortable reading on a 4K display at 100% OS scale.
- The tray icon is now SVG-sourced and rasterized at each display's scale factor — crisp on any HiDPI panel, rendered correctly as a dark-mode template, and cleared cleanly when the count returns to zero.
- Continuous integration runs lint, type-check, and tests on every pull request.
