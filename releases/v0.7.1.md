SpecForge v0.7.1

A small Windows quality-of-life patch: git now works invisibly.

## 🩹 Fixes

- **No more flashing console windows on Windows** — SpecForge runs `git` (and, for WSL-hosted workspaces, `wsl.exe`) many times in the background; each call used to flash a console window on screen, and with a WSL workspace registered the 10-second poll turned that into a constant strobe. Git child processes are now spawned without a visible console window. macOS and Linux are unaffected.

### Downloads

- **macOS** — `SpecForge_0.7.1_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and

  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.7.1_x64-setup.exe` (installer, recommended —

  `SpecForge_0.7.1_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.
