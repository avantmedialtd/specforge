SpecForge v0.15.0

Two things the app was quietly missing: every view now has an address you can link to, and the pane you're reading keeps itself up to date.

## ✨ Highlights

- **Every view has a URL.** Until now "what am I looking at" lived only in component state, so it had no name. In the browser that was a real gap: a reload dropped you back on the Dashboard, the Back button left the application entirely, and there was no way to send anyone a link to a specific change. Now the address bar tracks what you're viewing — `/w/<workspace>/<change>/tasks`, `/w/<workspace>/<change>/specs/<capability>`, `/archive/<workspace>/<change>`, `/settings` — so reloading keeps your place, Back and Forward move through the views you visited, and a link to a spec is just a link you can paste to someone.

  Links are built from **registry slugs derived from a workspace's stable name, never from its filesystem path** — so a URL never publishes your host directory layout into a bookmark or someone else's browser history, and a slug that matches no registered workspace resolves to "not found" without reading anything from disk. Renaming a workspace's display label for presentation doesn't break existing links either, since the slug isn't derived from the override.

  The desktop app gets the same addressability with an in-memory history stack driving the same code, plus keyboard **back/forward gestures** — so navigation behaves identically whether you're in the native shell or the browser.

- **The detail pane refreshes itself while you read it.** The tree pane has always updated live from the file watcher; the pane you were actually reading did not. Open `tasks.md` while an agent works through it and the checkboxes now tick in front of you, with no click away and back.

  The details are where this either works or annoys: your **scroll position is held** across a background refresh, so a live `tasks.md` never yanks you back to where you clicked minutes ago. A refresh whose content is unchanged is **completely invisible** — no re-render, no reflow, no flicker. There's **no spinner flash** for a read you didn't ask for. And if a background read fails — the change gets archived, the file is removed underneath you — the pane **keeps the text you were reading** instead of blanking to an error. A read you *did* trigger by clicking still reports its errors as before.

  The terminal client (`specforge-tui`) gets the same behaviour under the same contract, including holding its scroll offset, rather than the two frontends drifting apart.

## 🔧 Improvements

- Addresses are the **shortest form that's unambiguous** — a change that exists once doesn't carry an instance segment, a uniquely-named workspace uses its bare slug. When an address that used to be unique has since become ambiguous, the app presents the choice rather than silently guessing which one you meant.
- Following a deep link **reveals** the target node in the tree without rewriting your saved collapse/expand preferences — the reveal is transient and reverts when you navigate away, so opening someone else's link never quietly rearranges your own tree.
- Disclosure toggles and keyboard focus traversal no longer pile up history entries, so Back goes to the previous *view* rather than undoing an expand you did on the way there.
- Deep links survive a cold load: the served UI resolves the address once the workspace list arrives and opens what it names, without flashing the Dashboard on the way.

### Downloads

- **macOS** — `SpecForge_0.15.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.15.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.15.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.15.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.15.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.15.0_windows-x64.zip`.

#### Standalone Web Server (`specforge-serve`)

The headless web server, one archive per platform — extract and run
`./specforge-serve`. It binds `127.0.0.1:4317` by default; `--bind 0.0.0.0` (or
any other interface address) publishes it on the network, **unauthenticated**
— only do this on a network you trust:

- **macOS** — `specforge-serve_0.15.0_macos-universal.tar.gz` (Apple
  Silicon + Intel). **Unsigned**, and a terminal binary has no right-click ▸
  Open dialog, so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-serve`.
- **Linux** — `specforge-serve_0.15.0_linux-x64.tar.gz`.
- **Windows** — `specforge-serve_0.15.0_windows-x64.zip`.
