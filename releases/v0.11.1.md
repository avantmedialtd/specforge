SpecForge v0.11.1

The Claude quota gauge learns to watch per-model caps, and finished work finally looks finished.

## ✨ Highlights

- **Per-model quota windows in the Claude gauge.** Some models — like Fable — now meter against their own weekly cap, separate from the shared pooled budget, and that cap can bind well before the pooled one does. The gauge used to be blind to this: it only ever looked at the two pooled windows (5-hour and weekly), so a model could be nearly exhausted while the gauge still read comfortably green. It now reads Anthropic's per-model `limits[]` data and renders an extra weekly window for each scoped model, labeled by name, right alongside the existing 5-hour and weekly bars — same segments, same live "now" marker, same thresholds. Available in both the desktop sidebar and the terminal UI. Nothing changes when no scoped limits are present.

## 🔧 Improvements

- **Completed work now looks complete.** A finished section, artifact, or change used to swap its progress meter for a muted grey checkmark — visually indistinguishable from "nothing happening," and the opposite of what green usually means. Finished milestones now get a filled green disc instead, and a completed change's left rail turns green too, so a glance down the tree tells you what's actually done. Completed task labels pick up the same green, layered on top of the existing strikethrough. Selection still wins over all of it — a selected completed row still shows the accent selection bar.

### Downloads

- **macOS** — `SpecForge_0.11.1_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.11.1_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.11.1_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.
