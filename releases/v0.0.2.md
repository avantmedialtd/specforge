SpecForge v0.0.2

## 🩹 Fixes

- Every platform download now attaches to the release. The previous build published only the macOS `.dmg`, leaving the Windows installer and the Linux `.deb` / `.AppImage` missing — this release ships all three.

---

### Downloads

- **macOS** — `SpecForge_0.0.2_universal.dmg` (Apple Silicon + Intel). Unsigned build: on first launch, right-click ▸ **Open**, or clear the quarantine flag: `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.0.2_x64-setup.exe` (installer — ensures the Microsoft Edge WebView2 runtime).
- **Linux** — `.deb` or `.AppImage`.

**Full Changelog**: https://github.com/avantmedialtd/specforge/compare/v0.0.1...v0.0.2
