SpecForge v0.19.0

The headless web server is now a one-command install, and the Linux builds run
everywhere.

## ✨ Highlights

- **The headless web server is on npm.** `npx @avantmedia/specforge` starts the
  browser UI in any directory containing an `openspec/` workspace — no download,
  no extraction, and no macOS quarantine step, because files installed by a
  package manager are not flagged the way browser downloads are. Only your
  platform's binary is fetched.
- **Linux `arm64` builds.** `specforge-serve` now ships for `arm64` alongside
  `x64`, covering ARM servers and single-board machines — which is where a
  headless server most often actually runs.

## 🔧 Improvements

- **The Linux server binaries are statically linked against musl.** One binary
  now covers Alpine and container images as well as current and older glibc
  distributions, instead of needing a glibc at least as new as the build
  machine's.
- Release artifacts and the npm packages are built once and shipped to both
  channels, so the two are byte-identical.
- npm packages carry build provenance, attesting which repository and workflow
  run produced them. This is not code signing; the binaries remain unsigned, as
  all SpecForge artifacts are.
- Prerelease tags are now published as GitHub prereleases and to npm's `next`
  dist-tag, so a release candidate never displaces a stable release.

## 🩹 Fixes

- **The Linux `specforge-serve` download would not start on older
  distributions.** It was dynamically linked against the build runner's glibc
  (2.39), so it failed on Debian 12, Ubuntu 22.04, and RHEL 8 with a C-library
  version error. The static musl build above fixes this everywhere.

### Downloads

- **macOS** — `SpecForge_0.19.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.19.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.19.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.19.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.19.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.19.0_windows-x64.zip`.

#### Standalone Web Server (`specforge-serve`)

The headless web server. The quickest way to run it is npm — no download, and
**no quarantine step**, because npm installs are not flagged the way browser
downloads are:

```bash
npx @avantmedia/specforge          # or: npm install -g @avantmedia/specforge
```

Only your platform's binary is fetched. It binds `127.0.0.1:4317` by default;
`--bind 0.0.0.0` (or any other interface address) publishes it on the network,
**unauthenticated** — only do this on a network you trust.

Prefer a direct download? One archive per platform — extract and run
`./specforge-serve`:

- **macOS** — `specforge-serve_0.19.0_macos-universal.tar.gz` (Apple
  Silicon + Intel). **Unsigned**, and a terminal binary has no right-click ▸
  Open dialog, so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-serve`. (This does not apply to
  the npm install above.)
- **Linux** — `specforge-serve_0.19.0_linux-x64.tar.gz` or
  `specforge-serve_0.19.0_linux-arm64.tar.gz`. Statically linked against
  musl, so one binary covers Alpine and containers as well as current and
  older glibc distributions.
- **Windows** — `specforge-serve_0.19.0_windows-x64.zip`.
