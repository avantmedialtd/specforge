SpecForge v0.9.0

A third skin: SpecForge now runs in the browser — locally, or reachable from your other devices over Tailscale.

## ✨ Highlights

- **Optional local web UI.** SpecForge gains a browser skin over the same OpenSpec state the desktop app and `specforge-tui` already render. Run the standalone `specforge serve` binary, or flip the toggle in the desktop app's Settings to serve the dashboard from the running instance — the browser tab becomes a live mirror of desktop state, sharing one watcher with zero state contention. The same React bundle powers all three frontends; it detects its host and swaps its transport (Tauri IPC ↔ HTTP + SSE) automatically, so live updates stream into the browser exactly as they do on the desktop. The server binds `127.0.0.1` only and validates the request's `Origin`/`Host`, so an unrelated web page in your browser can't drive your local files. Read-only, like the desktop app.

- **Reach the web UI from your phone or laptop over Tailscale.** A new opt-in Tailscale Serve mode lets `tailscale serve` carry the web UI across your tailnet — real HTTPS via MagicDNS, device authentication, and per-user identity — while the app stays bound to loopback. The trust boundary becomes a configurable allowlist that trusts the node's own tailnet name (auto-discovered, with a manual override) on top of loopback; everything else is still refused. Optionally restrict access to specific Tailscale logins via an allow-list. No raw `0.0.0.0` binding and no Funnel — off by default.

- **Terminal UI colour schemes.** The terminal frontend's single hardcoded dark look becomes a choice. Pick a named scheme in the Settings screen — **Default**, **High contrast**, **Monochrome**, **Nord**, **Gruvbox**, or **Terminal-native** (which defers to your terminal's own ANSI palette so SpecForge blends into an already-themed terminal). The choice persists and applies live without a restart, and always composes with capability downsampling and `NO_COLOR` rather than overriding them.

## 🔧 Improvements

- **Capped, responsive TUI Browse sidebar.** The Browse screen's flat 42/58 split is replaced by a clamped sidebar width: it scales down on narrow terminals and stops growing past a sensible maximum on wide ones, so the artifact-detail pane — the actual content — always gets the surplus columns. The two-pane/one-pane threshold and focus model are unchanged.

- **SSH / Tailscale port-forward hints in the Web UI settings.** The web settings surface now shows the commands for reaching the UI from another device, so remote access is discoverable rather than something you have to look up.

### Downloads

- **macOS** — `SpecForge_0.9.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.9.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.9.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.9.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.9.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.9.0_windows-x64.zip`.
