SpecForge v0.16.0

Two ways to make the window yours: hide the panes you aren't using, and keep the changes you're actually driving at the top of the tree.

## ✨ Highlights

- **Hide either side pane.** The workspace tree on the left and the commit rail on the right were permanent fixtures — on a laptop screen or a narrow browser tab they squeezed the reading column below comfortable width even when all you wanted was to read one artifact. Both now have independent visibility toggles: `Cmd/Ctrl+B` for the sidebar, `Cmd/Ctrl+Alt+B` for the commit rail, in the desktop app and the served web UI alike. Any combination is reachable, and hiding both gives you a full-width reading view.

  Where there's no menu bar to discover this from — the web UI, Windows, Linux — each pane carries a small **collapse chevron** at its top, and a mirrored restore chevron appears in the corresponding corner of the center pane once the pane is gone. On macOS the application menu grows a **View submenu** carrying both toggles with their accelerators.

  A hidden rail also stops doing work: with it collapsed the commit graph isn't fetched at all, so re-targeting the rail's repository while it's hidden costs nothing — the fetch happens when you bring it back. Each pane's visibility persists across sessions, and pane **widths are remembered independently of visibility**, so restoring a pane brings back the width you left it at. With the sidebar hidden on macOS, the center pane takes over the traffic-light clearance so content still clears the window controls.

- **Star the changes you're actually working on.** Active changes rendered in fixed alphabetical order, so in a busy repository the one or two you're driving sat buried among a dozen dormant ones, and nothing let you say "keep these on top." Every change row now carries a **star** — revealed on row hover or keyboard focus, filled in the accent colour once set — and starred changes float to the front of their group, alphabetical within each partition. No divider, no section header: the filled star is its own explanation for the ordering.

  Stars attach to the **change itself, not to its position in the tree**. A star survives a change being promoted from a single row to a multi-worktree group, survives worktree churn, and survives an archive round-trip — archive a starred change and it comes back starred if it returns. `Cmd/Ctrl+D` toggles the star on the focused row so the feature isn't pointer-only, and clicking the star never selects the row out from under you.

## 🔧 Improvements

- Pane visibility is **ambient view state** — it never enters the address bar or your navigation history, so hiding a pane doesn't add a Back step, and a link you share doesn't impose your layout on whoever opens it.
- Favorites are written back as an **add/remove delta merged under the settings lock** rather than a whole-list overwrite — a failed load can't echo an empty list over your stored stars, and two connected clients compose instead of clobbering each other.

### Downloads

- **macOS** — `SpecForge_0.16.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.16.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.16.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.16.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.16.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.16.0_windows-x64.zip`.

#### Standalone Web Server (`specforge-serve`)

The headless web server, one archive per platform — extract and run
`./specforge-serve`. It binds `127.0.0.1:4317` by default; `--bind 0.0.0.0` (or
any other interface address) publishes it on the network, **unauthenticated**
— only do this on a network you trust:

- **macOS** — `specforge-serve_0.16.0_macos-universal.tar.gz` (Apple
  Silicon + Intel). **Unsigned**, and a terminal binary has no right-click ▸
  Open dialog, so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-serve`.
- **Linux** — `specforge-serve_0.16.0_linux-x64.tar.gz`.
- **Windows** — `specforge-serve_0.16.0_windows-x64.zip`.
