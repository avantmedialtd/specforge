SpecForge v0.3.0

The home surface grows up: a real Dashboard, and a daily sense of momentum.

## ✨ Highlights

- **Dashboard home surface** — open the window and land on a global, all-workspaces overview instead of an empty pane: cross-workspace task rollups, a per-repository breakdown, a commits-per-day activity chart, and change-throughput and time-to-archive metrics mined from your git history. Read-only and computed on demand.
- **Today's Progress** — a gamified band at the top of the Dashboard celebrates what you got done today: animated counts of changes shipped, changes started, commits landed, and tasks completed, each compared to your recent daily average — plus an active-day streak counter, a contribution heatmap with day drill-down, milestone badges, and a confetti burst when a change ships (honouring reduced-motion).
- **Enriched About panel (macOS)** — the system About box now states what SpecForge is — a menu-bar viewer for OpenSpec workspaces — alongside its version, copyright, repository link, and license.

## 🔧 Improvements

- **Commit trailers in the detail pane** — a commit's git trailers (like `OpenSpec-Id` and `Co-Authored-By`) now render as a labelled key/value list instead of being dropped from the message.
- **Friendlier commit-graph dates** — day separators read `Today`, `Yesterday`, or the plain weekday for recent commits, falling back to absolute dates beyond a week.
- The Dashboard fills the full width of its pane on larger displays instead of floating a narrow centred column.
- Today's Progress tiles lead with the north star: shipped → started → commits → tasks.
- A refreshed forge-themed application bundle icon, and a tighter workspace-tree sidebar.

### Downloads

- **macOS** — `SpecForge_0.3.0_universal.dmg` (Apple Silicon + Intel). Unsigned build: on first launch, right-click ▸ **Open**, or clear the quarantine flag: `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.3.0_x64-setup.exe` (installer, recommended — ensures the Microsoft Edge WebView2 runtime) or `SpecForge_0.3.0_x64-portable.exe` (single file; uses the system WebView2 runtime, preinstalled on Windows 11 and maintained Windows 10 — use the installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.
