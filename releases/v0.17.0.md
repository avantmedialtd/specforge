SpecForge v0.17.0

The game comes out, the record stays — and every artifact you read now tells you what it is, whose branch it's on, and when it last moved.

## ✨ Highlights

- **The progress layer is on for everyone, and the season game is gone.** The app's most characterful surfaces — the streak, the contribution heatmap, the per-author leaderboard, the commit garden, the ship confetti — used to sit behind an opt-in switch that defaulted to **off**. That meant the default SpecForge experience was a bare analytics table, and the good half of the Dashboard was invisible unless you went looking for a toggle in Settings.

  That switch also bundled two very different things. On one side: views derived directly from work you actually did — days active, tasks completed, changes shipped, commits landed. On the other: a **season system** — a monthly battle pass with a 30-tier ladder, adaptively-paced totals, rotating generated objectives, a treatment vault with rarity tiers, season recaps, and a locker of cosmetic badge finishes. That second half was invented scoring, a game layered on top of the record rather than a reading of it.

  So the gate is deleted and the game is deleted. What survives is the honest half — permanent, unconditional, and no longer optional. `prefers-reduced-motion` remains the only thing that suppresses motion.

- **The served web UI is usable on a tablet.** Measured against the real bundle at iPad Pro geometry, three assumptions broke: the Settings entrypoint was cut in half with both usage-quota strips stranded below an unscrollable fold, the pane dividers could not be dragged at all, and the pane-visibility chevrons were invisible in practice because they were revealed only on a hover that never fires. Compounding all three, every iPad and iPhone user-agent matched the frontend's `/Mac/i` test, so a touch browser switched on macOS window chrome — 32pt of traffic-light padding in both side panes, and a full-width invisible drag strip that swallowed taps.

  Now the shell sizes itself to the viewport it can actually see, so bottom-anchored sidebar chrome — Archive, Settings and the quota strips — stays reachable in both orientations. Dividers accept **pointer** input, so mouse, touch and pen all resize the panes through the same clamps. Where the device has no hover, the pane chevrons and the change-row favorite star are persistently visible at touch-sized targets. And macOS window chrome now keys off the native shell rather than the user-agent, so the served UI never reserves traffic-light space and never renders the tap-eating drag region — on an iPad or on a Mac browser.

- **The reading surfaces name the change you are looking at — and copy it on click.** A change's directory name is the token you hand a coding agent: the argument to `/opsx:apply`, the folder to open, the thing you type when you want work done on a change. It was displayed nowhere you could copy it from — the sidebar shows the proposal *title*, the folder name survived only in a hover tooltip, and the detail pane was the one center-pane view with no header at all.

  The detail pane now carries a **change-identity header**: the change directory name, the owning worktree's branch as a chip **tinted to the workspace's palette colour** (matching the tree's chip for the same branch), and how long ago the artifact last changed. The archive reading header gains the on-disk `YYYY-MM-DD-<id>` directory name; the file-browser preview gains the selected file's root-relative path.

  **One click copies the value** and selects it at the same time — the highlight is immediate confirmation of exactly what landed on your clipboard, and if a clipboard write is refused the value is already selected for the platform's own copy shortcut. Each identity is a real tab stop with Enter/Space activation and the house focus ring. Confirmation flashes the ink rather than swapping the label, so the row never reflows under your cursor.

- **"Last changed" answers the question freshness cannot.** The open artifact was already re-read on every watcher batch, so the bytes on screen were never stale — but a proposal edited four minutes ago and one abandoned twelve days ago rendered identically. The identity header now shows a relative label (`just now`, `9 min ago`, `12 days ago`) that **advances on its own** while the pane is open, in a reserved constant-width box so a ticking timer can never re-wrap the change name mid-identifier while you are reading it.

## 🔧 Improvements

- **The tray is one attention surface again.** The badge counted parked workspaces out, but the menu-bar *glyph* read the raw cache — so a parked repository's spec deltas kept flipping the icon while contributing nothing to the badge beside it. Both now share a single row-exclusion rule.
- **The terminal gets the whole disable feature.** `specforge-tui` hid a parked row but offered no way to park one and no sign that any were parked. Space now toggles the focused workspace in Settings, the row renders a `(disabled)` marker, and the terminal Dashboard carries the same "includes N disabled workspaces" note the React one has.
- **A parked address says so.** A deep link into a disabled workspace used to read as "not found". Address resolution gains a fourth outcome that names the workspace and offers a one-click re-enable.
- **A shared switch says what it governs.** Rows sharing a presentation key with siblings now carry a note that the toggle moves them together, and a rejected toggle reports that it failed instead of appearing to succeed.
- **The desktop stops re-implementing the shared view accessor.** The Tauri command duplicated both the disabled filter and the presentation join; it now delegates to the shared service, moving the desktop's behaviour into the crate that `cargo test` and `cargo mutants` can actually reach.
- **The relative-time vocabulary is unified.** Two private copies had already drifted apart — "12s ago" against "just now", weeks and months in one and not the other. All three surfaces now read one tested definition, with the cadence function and width bound that none of the copies had.
- **The macOS titlebar strip no longer eats clicks.** An audit of the top 32px of the window found the invisible drag region also blocking the file browser's filter input and Refresh button, the commit breadcrumb, both split-pane dividers, and — once scrolled — Settings' form controls and every markdown link. Fixed across all of them.
- The tree chip and the header chip now share one appearance definition, so the hand-copy that let them drift apart cannot recur. The tree renders identically.

## 🗑 Removed

- **The season / battle-pass system in full** — the monthly season model and its deterministic naming, two-track progression, season scoring, the 30-tier ladder and named bands, adaptive pacing and the overflow lane, rotating generated objectives, season rollover and recaps, the vault, and the seasonal leaderboard variant.
- **Badge finishes** — procedural treatments, rarity, the treatment locker, the equip action, and the Settings *Badge finishes* section. The identicon reverts to its plain, deterministic form.
- **The permanent career tier** and its `◆ <rank>` chip on the Dashboard hero — the last consumer of the scoring module.
- **The gamification master switch**, its setting, its IPC commands and its TUI toggle row. No migration is needed: an existing `settings.json` carrying the old keys deserializes straight past them, and the next write drops them.
- **The terminal's Season screen**, with the remaining screens renumbered contiguously: Browse `1`, Dashboard `2`, Garden `3`, History `4`, Settings `5`.

## 🩹 Fixes

- **A parked repository keeps the name it had while enabled.** The no-subprocess cold path resolved a repository's main worktree as "the parent of the common dir", which is correct only for the `<work>/.git` layout — so parking a submodule renamed it to `modules`, and a `--separate-git-dir` or bare repository fared no better. The fallback now reproduces git's own rule, which also fixes the identical latent bug in default-branch detection running `git branch --show-current` against a submodule's *superproject*.
- **Dashboard ships resolve by repository, not by worktree path.** A ship in today's feed now finds its owning row by repository identity, fixing the parked case and the enabled-feature-worktree case together; a ship whose row is absent from the tree is marked and routes to Settings instead of silently swallowing the click.
- **The footnote counts rows, not folders.** The "includes N disabled workspaces" figure counts top-level rows, deduplicated by presentation key, on both frontends.
- **A no-op write no longer freezes the timestamp.** The detail pane's equality guard widens from the body to the body *and* its modification time, so a branch switch or an idempotent rewrite updates "last changed" instead of leaving the old value on screen indefinitely.
- **A ship with no recoverable archival instant renders no archive-time text at all**, instead of a dangling "archived" with nothing after it.

### Downloads

- **macOS** — `SpecForge_0.17.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.17.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.17.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.17.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.17.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.17.0_windows-x64.zip`.

#### Standalone Web Server (`specforge-serve`)

The headless web server, one archive per platform — extract and run
`./specforge-serve`. It binds `127.0.0.1:4317` by default; `--bind 0.0.0.0` (or
any other interface address) publishes it on the network, **unauthenticated**
— only do this on a network you trust:

- **macOS** — `specforge-serve_0.17.0_macos-universal.tar.gz` (Apple
  Silicon + Intel). **Unsigned**, and a terminal binary has no right-click ▸
  Open dialog, so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-serve`.
- **Linux** — `specforge-serve_0.17.0_linux-x64.tar.gz`.
- **Windows** — `specforge-serve_0.17.0_windows-x64.zip`.
