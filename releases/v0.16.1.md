SpecForge v0.16.1

Park the repositories you aren't touching this week — without losing a single streak day.

## ✨ Highlights

- **Temporarily disable a workspace.** A long-lived registry accumulates workspaces faster than it sheds them: after a dozen repositories, the tree pane, the tray badge and the desktop notifications are all reporting on projects you aren't working on. The only escape hatch was unregistering, which is too destructive to reach for casually — it cascades away every discovered worktree, drops the display name and tint, and forfeits the row's position in your ordering.

  Every top-level row — a repository group or a flat workspace — now carries a **toggle in Settings**. Flip it off and the row leaves the tree, stops counting toward the tray badge, and stops raising notifications. Flip it back on and it returns immediately, with its name, colour and position intact. The switch is indefinite and reversible; nothing is unregistered and nothing is deleted.

  Parking is an **attention** control, not an existence control, and the distinction is load-bearing: the filesystem watcher keeps running, the parsed cache stays warm, and achievements keep being recorded for a disabled workspace. Your streak, contribution heatmap, season score and career tier are exactly what they would have been. The **Dashboard is deliberately unfiltered too** — summary counters, the per-repository breakdown, the activity chart, lifecycle throughput and today's ships all keep counting a parked repository, and a footnote spells the asymmetry out (`… · includes 2 disabled workspaces`) so the gap between the tree and the totals reads as intent rather than a bug.

  A parked repository also **stops costing you recompute time**: it is aggregated *cold*, from the already-warm cache plus a single directory read, skipping the `git worktree list`, `git branch` and `git status` sweep that dominates a full refresh. Re-enabling is a scoped refresh against that same warm cache — no watcher restart, no re-parse.

  Because the filter lives in the shared view command rather than in each frontend, the **desktop app, the served web UI and `specforge-tui` all inherit it** with no per-client work.

## 🔧 Improvements

- The disabled flag is stored in the presentation store alongside display names and tints — so it inherits automatic cleanup when a workspace is unregistered, and `workspaces.json` keeps its no-schema-version, any-version-reads-and-writes format guarantee untouched.
- Toggling a workspace off can no longer clobber its display name or colour: the flag is written as a targeted read-modify-write rather than a whole-entry replacement, and an entry carrying only the disabled flag is no longer pruned on save (which would have silently un-parked it on the next launch).

### Downloads

- **macOS** — `SpecForge_0.16.1_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.16.1_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.16.1_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.16.1_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.16.1_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.16.1_windows-x64.zip`.

#### Standalone Web Server (`specforge-serve`)

The headless web server, one archive per platform — extract and run
`./specforge-serve`. It binds `127.0.0.1:4317` by default; `--bind 0.0.0.0` (or
any other interface address) publishes it on the network, **unauthenticated**
— only do this on a network you trust:

- **macOS** — `specforge-serve_0.16.1_macos-universal.tar.gz` (Apple
  Silicon + Intel). **Unsigned**, and a terminal binary has no right-click ▸
  Open dialog, so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-serve`.
- **Linux** — `specforge-serve_0.16.1_linux-x64.tar.gz`.
- **Windows** — `specforge-serve_0.16.1_windows-x64.zip`.
