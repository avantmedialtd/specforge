SpecForge v0.7.0

SpecForge now lives where you work: repos inside WSL on Windows, and a browser you can drive entirely from the keyboard.

## ✨ Highlights

- **Full keyboard navigation** — the workspace tree is now a real ARIA tree with a single Tab stop: Arrow keys walk the visible rows, Left/Right collapse, expand, and jump to parents, Home/End hit the extremes, Enter/Space activates, and typing a letter jumps to the next matching row. Resting on an artifact briefly opens it in the reading pane, so holding ↓ skims without loading every row on the way. Split-pane dividers resize with arrow keys, Escape dismisses Settings and the Archive, and every focusable control now shows the indigo focus ring. Screen readers get the full picture: levels, expanded/selected state, and named separators.
- **WSL workspace support (Windows)** — workspaces living in the WSL2 Linux filesystem (reached via `\\wsl.localhost\<distro>\…`) now work: a polling watcher keeps them fresh across the 9P boundary where Windows file notifications never arrive, and git queries run through `wsl.exe` inside the distro. The poll cadence defaults to 10s and is configurable in Settings (shown on Windows only).

## 🔧 Improvements

- The **Today's commits** garden now shows only workspaces that actually moved today — quiet, non-git, and unavailable workspaces no longer render placeholder boxes, and on a fully quiet day the section steps aside entirely.
- Workspace tint swatches in Settings have larger click targets and proper radio-group semantics (arrow keys move between colours).

## 🗑 Removed

- The three **Overview** summary cards on the Dashboard (task rollup, "changes touch specs", repos · worktrees). The per-repository breakdown and the footer's active-change count already carry that signal.

## 🩹 Fixes

- Pressing Escape while renaming a workspace now truly abandons the edit — previously the discarded text could still be saved.
