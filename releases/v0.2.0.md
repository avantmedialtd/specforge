SpecForge v0.2.0

A new commit-graph rail, a bolder look, and a portable Windows build.

## ✨ Highlights

- **Commit-graph rail** — a faithful git commit graph now lives in an always-on pane on the right, scoped to whichever repository you have selected. Branch and merge lanes, refs, tags, and HEAD render just like a desktop git client; click any commit to see its changed files and diff in the detail pane — no more leaving SpecForge to run `git log --graph`.
- **Elevated visual identity** — a top-to-bottom dark redesign gives surfaces real depth and separation, crisper borders, brighter AA-clean text, and a confident indigo accent. The calm pro-tool feel stays; the washed-out flatness is gone.
- **Windows portable build** — every release now ships a single-file `SpecForge_<version>_x64-portable.exe` alongside the installer. Download one file, double-click, run — handy for USB sticks or locked-down machines where you can't run an installer.

## 🔧 Improvements

- Task progress now reads at a glance: the sidebar's `completed/total` counter became a fill bar, with the exact count preserved on hover and for screen readers (hidden once a change hits 100%).
- Completed tasks in the sidebar tree are now struck through and dimmed instead of relying on a tiny checkbox glyph — easier to scan, and a non-colour cue.
- The commit-graph rail groups commits into calendar-day sections with labelled day separators, turning the flat list into a skimmable timeline.

### Downloads

- **macOS** — `SpecForge_0.2.0_universal.dmg` (Apple Silicon + Intel). Unsigned build: on first launch, right-click ▸ **Open**, or clear the quarantine flag: `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.2.0_x64-setup.exe` (installer, recommended — ensures the Microsoft Edge WebView2 runtime) or `SpecForge_0.2.0_x64-portable.exe` (single file; uses the system WebView2 runtime, preinstalled on Windows 11 and maintained Windows 10 — use the installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.
