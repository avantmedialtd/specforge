SpecForge v0.8.2

The terminal client can now manage its own workspaces — no desktop round-trip.

## ✨ Highlights

- **Manage workspaces from the terminal.** The `specforge-tui` Settings screen (press **`6`**) gains a **Workspaces** section beneath the two toggles. **Add** a workspace by typing or pasting an absolute path into a one-line prompt — the same validation the desktop uses (the path must exist, be a directory, and contain an `openspec/` subdirectory) is surfaced inline if it fails. Each registered workspace gets a row showing its name, path, and a missing/stale indicator; from there press **`x`** to **remove** it (with a confirmation that names any discovered git worktrees the cascade will also drop), **`r`** to **rename** its display label (clear the field to fall back to the folder name), and **`c`** to **cycle a palette colour** through the eight curated tokens plus "none". Renames and colours persist immediately; adds and removes refresh the tree live. Terminal-only users over SSH or in tmux no longer need to open the desktop app just to register a folder.

## 🔧 Improvements

- The register / unregister watcher orchestration and the workspace name/colour write now live in the shared application service, so the desktop and terminal frontends drive workspace management through one tested code path. Desktop behaviour is unchanged.

### Downloads

- **macOS** — `SpecForge_0.8.2_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.8.2_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.8.2_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

`./specforge-tui`:

- **macOS** — `specforge-tui_0.8.2_macos-universal.tar.gz` (Apple Silicon +
