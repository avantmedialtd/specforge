SpecForge v0.20.0

Wide diagrams get a zoomable full-window view, and the whole toolchain moves up
a major version.

## ✨ Highlights

- **Maximize any diagram or figure.** A wide mermaid diagram in a narrow detail
  pane was silently scaled down until its labels were unreadable, and nothing in
  the UI offered a way back — the horizontal scrollbar that looked like an
  escape hatch could never fire, because content capped at the pane's width
  cannot overflow it. Every successfully rendered diagram and `svg` figure now
  carries a corner control that opens it in a view above the whole window, which
  you can zoom and pan: wheel or trackpad to zoom anchored under the pointer,
  drag to pan, pinch on a touch screen, plus explicit **Zoom in**, **Zoom out**,
  **Fit to window**, and **Actual size** controls so it is fully operable
  without a wheel or trackpad. Escape, the close button, or a click on the
  backdrop returns you to the artifact with your reading position untouched.
- **Zoomed figures stay sharp.** The maximized view re-renders the figure at
  each new scale rather than magnifying a fixed image, so a diagram at the 8×
  ceiling is as crisp as at 100%. It also tracks the active colour scheme —
  switch between light and dark while zoomed and the figure re-renders in place,
  keeping both your zoom level and your position.
- **Reading is unchanged.** A figure still fits the pane's width inline; the
  maximized view is an escape hatch, not a new default. Fences that failed to
  render, and diagrams still in flight, carry no control — there is nothing to
  maximize.

## 🔧 Improvements

- **The whole dependency stack moved up a major version**, with no intended
  change in behaviour: React 19 and react-markdown 10, Vite 8, and TypeScript 7
  on the frontend; axum 0.8 for the web server, ureq 3 for the usage-quota
  pollers, ratatui 0.30 with crossterm 0.29 and pulldown-cmark 0.13 for the
  terminal UI, plus thiserror 2, dirs 6, and resvg 0.48 for the tray icon.
- **The supported-platform floor is deliberately unchanged.** Vite 8 would have
  raised the bundle's syntax baseline to Chrome 111 / Safari 16.4, quietly
  dropping machines SpecForge still claims to support — macOS 11 ships the
  WebKit that pairs with Safari 14. The build target is pinned to the previous
  baseline, so which machines run SpecForge stays a product decision rather than
  a side effect of a build-tool upgrade.
- **The README leads with npm.** `npx @avantmedia/specforge`, introduced last
  release, is now the first install path shown, ahead of the desktop and
  terminal downloads — it is the one with nothing to download and no Gatekeeper
  or SmartScreen prompt to clear.

### Downloads

- **macOS** — `SpecForge_0.20.0_universal.dmg` (Apple Silicon + Intel).
  This build is **unsigned**: on first launch, right-click the app ▸ **Open** and
  confirm, or clear the quarantine flag:
  `xattr -dr com.apple.quarantine /Applications/SpecForge.app`.
- **Windows** — `SpecForge_0.20.0_x64-setup.exe` (installer, recommended —
  ensures the Microsoft Edge WebView2 runtime) or
  `SpecForge_0.20.0_x64-portable.exe` (single file; uses the system WebView2
  runtime, preinstalled on Windows 11 and maintained Windows 10 — use the
  installer if your machine lacks it).
- **Linux** — `.deb` or `.AppImage`.

#### Terminal UI (`specforge-tui`)

The standalone terminal client, one archive per platform — extract and run
`./specforge-tui`:

- **macOS** — `specforge-tui_0.20.0_macos-universal.tar.gz` (Apple Silicon +
  Intel). **Unsigned**, and a terminal binary has no right-click ▸ Open dialog,
  so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-tui`.
- **Linux** — `specforge-tui_0.20.0_linux-x64.tar.gz`.
- **Windows** — `specforge-tui_0.20.0_windows-x64.zip`.

#### Standalone Web Server (`specforge-serve`)

The headless web server. The quickest way to run it is npm — no download, and
**no quarantine step**, because npm installs are not flagged the way browser
downloads are:

```bash
npx @avantmedia/specforge          # or: npm install -g @avantmedia/specforge
```

Only your platform's binary is fetched. It binds `127.0.0.1:4317` by default;
`--bind 0.0.0.0` (or any other interface address) publishes it on the network,
**unauthenticated** — only do this on a network you trust.

Prefer a direct download? One archive per platform — extract and run
`./specforge-serve`:

- **macOS** — `specforge-serve_0.20.0_macos-universal.tar.gz` (Apple
  Silicon + Intel). **Unsigned**, and a terminal binary has no right-click ▸
  Open dialog, so clear the quarantine flag before the first run:
  `xattr -dr com.apple.quarantine specforge-serve`. (This does not apply to
  the npm install above.)
- **Linux** — `specforge-serve_0.20.0_linux-x64.tar.gz` or
  `specforge-serve_0.20.0_linux-arm64.tar.gz`. Statically linked against
  musl, so one binary covers Alpine and containers as well as current and
  older glibc distributions.
- **Windows** — `specforge-serve_0.20.0_windows-x64.zip`.
